# 🪦 Virtual # Buykevich.memory Memorial Park

Интерактивный 3D-мемориал с кладбищем и галактиками.

## 🚀 Управление

| Действие | Результат |
|----------|-----------|
| **Клик** | Захват мыши (FPS-режим) |
| **WASD** | Движение |
| **Q / E** | Вверх / Вниз |
| **Shift** | Ускорение |
| **Scroll** | Лететь вперёд/назад |
| **Телефон** | 1 палец — вращение, 2 пальца — зум/панорамирование |
